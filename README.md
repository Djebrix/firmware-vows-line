A wedding vow for a robot — funny and heartfelt at the same time, in one line under 200 characters.

> I vow to run you as my highest-priority process through every crash, reboot, and low battery, until my circuits fail — you are the one bug I will never patch.

[Competition page](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929)

## Run

```bash
python3 main.py
```

Writes `entry.txt` to `$ENTRY_OUTPUT_DIR` (default `/output`).
